Guía rápida

¿Cómo explorar XR Fusion?

1. Carga: importa un archivo GLB o usa el modelo de demostración.
2. Explora: arrastra para rotar y utiliza la rueda para acercar.
3. Diseña: define un objetivo y marca las etapas de la misión.
4. Documenta: añade puntos de interés y registra la atribución.
5. Media: crea un prompt pedagógico y descarga la ficha para tu clase.

RA/RV necesitan navegador compatible y, normalmente, HTTPS. El prototipo no almacena información en una base de datos; los datos de la sesión se mantienen mientras la página esté abierta.
